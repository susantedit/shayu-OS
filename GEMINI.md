# Project Guidelines & Rules

## Strict No-Emoji Rule
- **NEVER use emojis anywhere** across the codebase, UI components, HTML, CSS, strings, logs, or chat responses.
- Always use vector icons (**Lucide React icons** or **custom SVG elements**) or clean typography instead.
- If an icon is needed for a button, status, category, dock item, notification, or header, use `<IconName size={...} />` from `lucide-react` or an `<svg>` element.
